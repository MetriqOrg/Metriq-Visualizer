# Export profiles

These schema-4 `.mvexport` files are editable starting points. Load one in Export Studio, change any setting, and save it under a new name. Profiles contain delivery, presentation, and six-layer composition settings only; no source media or local source path is embedded.

Creator profiles default to clean scene-HUD/timecode output. The 4K analysis profile retains those technical overlays for scientific and instructional context.
