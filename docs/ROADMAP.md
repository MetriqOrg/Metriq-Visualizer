# Bounded roadmap

The roadmap prioritizes practical creator, education, and light scientific use.
It is not a commitment to turn Metriq Visualizer into an industrial DAW,
broadcast suite, laboratory acquisition system, or cloud platform.

## Near-term candidates

- Optional local sound-event/species classifier plug-in boundary, with explicit
  model provenance and confidence display.
- A/B comparison of two sources or two mappings.
- Region annotations and bookmark export.
- Batch application of a saved `.mvexport` profile to a small explicit source
  list.
- Additional scientific exports such as Parquet when the dependency/benefit
  tradeoff is justified.
- Better color-accessibility presets and printable classroom views.
- Signed/notarized release artifacts for supported desktop platforms.

## Performance candidates

- Optional GPU geometry preview while retaining the headless reference renderer
  for deterministic export.
- Incremental long-media analysis and visible cancellation.
- Preview-resolution adaptation under interaction.
- Shared decoded-frame cache with a strict memory budget.

## Deliberate non-goals

- paid tiers or feature gates;
- cloud-only rendering;
- account requirements;
- hidden telemetry;
- DRM;
- real-time safety alarms;
- unreviewed remote microphone upload;
- industrial device control;
- autonomous scientific conclusions.
